⟩ Quick Start

Up in 4 steps

One command installs everything. Then point and click.

01
Run the installer
One curl command installs Python, uv, clones the repo, and starts the server on port 3000.
curl -fsSL https://raw.githubusercontent.com/Get-Second-Step/clawboard-agent/main/install.sh | bash
02
Open your browser
Installer prints your VPS IP. Open it in any browser. No password needed yet.
http://your-vps-ip:3000
03
Connect Google Ads
Enter your Developer Token and Customer ID. One OAuth click. Refresh token saved locally.
Connect → Settings → Google Ads
04
Run your first audit
Hit "Run Audit" or type in the chat. PDF report delivered to Telegram in 2-3 minutes.
